## Dataset
Self-created dataset of 30 days (Oct 2026): daily data used (GB), calls (mins), screen time (hrs).

## Computation
Average, Maximum, Minimum, Total, Standard Deviation, Weekday vs Weekend totals and averages.

## Findings
- Average daily data usage is 2.38 GB.
- Average screen time is 5.86 hours per day.
- Weekend average data usage (3.29 GB) is higher than weekday (2.05 GB).
- Most days (17 days) data usage is between 1.4 and 2.23 GB.
- Screen time peaks on weekends.
